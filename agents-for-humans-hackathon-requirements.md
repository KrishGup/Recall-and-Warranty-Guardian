# Agents for Humans Hackathon — Requirements

**Deadline:** Sep 14, 2026 @ 8:00pm EDT

## What to Build
- A new AI agent built with the **Strands Agents SDK**
- Must do real work **end-to-end**, autonomously — not an app the user has to keep opening/managing, only surfacing for real decisions
- Enter one track:
  - **Everyday Agents** — daily life: home, money, health, errands, family
  - **Professional Agents** — repetitive, judgment-heavy work tasks
  - **Good Neighbor Agents** — helps groups (neighborhoods, nonprofits, schools, libraries, local orgs)
- Deploying with **Amazon Bedrock AgentCore** is optional but strengthens the Technical Implementation score

## Deliverables Checklist
- [ ] Text description — what it does, who it's for, how it works
- [ ] Public repo URL containing:
  - [ ] All source code, assets, setup instructions
  - [ ] MIT or Apache license (visible in repo's "About" section)
  - [ ] README
  - [ ] Architecture diagram
- [ ] Demo video (**max 5 min**)
  - [ ] Shows the project working
  - [ ] Pitch covers: (1) the problem, (2) who it's for, (3) why it matters
  - [ ] Slides / screen recording / voiceover fine — no camera required
- [ ] AWS Builder ID
- [ ] *(Optional)* Live demo link — boosts Technical Implementation score
- [ ] *(Optional bonus)* Build-journey post on builder.aws.com, titled with "Agents for Humans," published before the deadline

## Judging Criteria
| Criterion | What it's assessing |
|---|---|
| Technological Implementation | Depth/skill of Strands Agents use; genuine, non-trivial, working code; live demo/AgentCore help here |
| Design | Complete, coherent product experience — not just a proof of concept |
| Potential Impact | Credible, specific case for a real problem + real audience |
| Creativity & Originality | Non-obvious use of Strands Agents; real understanding of the problem space |
| Presentation | Video clearly shows it working end-to-end; pitch is clear and easy to follow |

## Prizes (context)
- Grand Prize: $10,000
- Per track (Golden / Silver / Bronze): $5,000 / $3,000 / $2,000
- $50 in AWS credits available via the Resources tab request form
